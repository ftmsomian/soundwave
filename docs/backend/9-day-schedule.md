# 🗓 برنامه‌ی ۹ روزه — فاز دوم (بک‌اند)

> فرض: روز ۱ صبح شروع می‌کنید. اگه شروع واقعی‌تون وسط روزه، همه‌چی رو یک نیم‌روز جلو بکشید.

## روز ۰ / صبح روز ۱ — هماهنگی مشترک (۱ الی ۲ ساعت، هر سه نفر با هم)
- توافق روی ERD نهایی (فیلدهای دقیق `User`, `Song`, `Album`, `Playlist`, `Notification`, `Ticket`)
- توافق روی فرمت خطا و pagination مشترک ([api-contract.md](api-contract.md))
- ساخت اسکلت ریپو بک‌اند + سه برنچ `backend/<name>-<app>`

## روز ۱
- **عضو۱:** اسکلت جنگو + `User` model اولیه + پوش فوری به `dev` (ظهر) + شروع JWT
- **عضو۲:** طراحی مدل `Song/Album/Playlist` روی کاغذ/ERD، اپ `catalog` رو با placeholder FK بساز
- **عضو۳:** طراحی مدل `Notification/Ticket/Pricing/Transaction`، اپ `platform_ops` رو با placeholder بساز
- **آخر روز:** هر سه از `dev` (که `User` واقعی توش هست) rebase کنن

## روز ۲
- **عضو۱:** تکمیل `Artist`, `Follow` model + endpoints ثبت‌نام/لاگین + permissions مشترک در `core/`
- **عضو۲:** نهایی کردن مدل‌های `Song/Album/Playlist` با FK واقعی به `User` + migrations
- **عضو۳:** نهایی کردن مدل‌های خودش + شروع `Notification` endpoints پایه

## روز ۳ — نقطه‌ی همگام‌سازی (Sync Point کوتاه، ۱۵-۲۰ دقیقه)
- چک کنید مدل‌های کلیدی (`User`, `Song`, `Artist`) دیگه تغییر ساختاری نمی‌کنن
- **عضو۱:** پروفایل (view/edit)، آپلود آواتار، محدودیت اشتراک روی آواتار
- **عضو۲:** CRUD کامل آهنگ/آلبوم + آپلود فایل صوتی/کاور
- **عضو۳:** CRUD تیکت‌ها + چت تیکت

## روز ۴
- **عضو۱:** فراموشی رمز عبور + تنظیمات کاربر (`UserSettings`) + دنبال کردن
- **عضو۲:** جستجو/فیلتر/مرتب‌سازی + endpoint استریم با محدودیت روزانه
- **عضو۳:** تأیید/رد هنرمند (`artist-requests`) + سیگنال‌های اعلان مربوطه

## روز ۵
- **عضو۱:** تست‌نویسی auth/profile + رفع باگ‌ها
- **عضو۲:** پلی‌لیست‌ها با اعمال سقف بر اساس اشتراک + endpoint «آثار من» برای هنرمند
- **عضو۳:** قیمت‌گذاری پویا (`pricing`) + شروع اتصال درگاه پرداخت (sandbox)

## روز ۶ — نقطه‌ی همگام‌سازی (Sync Point، ۳۰ دقیقه)
- بررسی مشترک: آیا محدودیت‌های اشتراک (پلی‌لیست، استریم، آواتار) از یک منبع مشترک (`core/subscription_rules.py`) می‌خونن؟
- **عضو۱:** رفع نواقص، شروع کمک به تست ادغام با فرانت‌اند بخش auth
- **عضو۲:** تست‌نویسی catalog + رفع باگ استریم/سقف پلی‌لیست
- **عضو۳:** تکمیل خرید اشتراک + callback درگاه پرداخت

## روز ۷
- **عضو۱:** اتصال فرانت‌اند auth/profile به بک‌اند واقعی (جایگزینی localStorage mock)
- **عضو۲:** اتصال فرانت‌اند صفحات آهنگ/آلبوم/پلی‌لیست/پخش‌کننده به بک‌اند
- **عضو۳:** اتصال فرانت‌اند اعلانات/تیکت/تنظیمات پرداخت/داشبورد مدیریت به بک‌اند + management command حسابرسی ماهانه

## روز ۸
- همه با هم: تست end-to-end کل فلوها (ثبت‌نام → تأیید هنرمند → انتشار اثر → استریم → محدودیت‌ها → اعلان → تیکت → خرید اشتراک → حسابرسی)
- رفع باگ‌های ادغام
- بررسی چک‌لیست نهایی ([final-checklist-backend.md](final-checklist-backend.md))
- (اختیاری) شروع Docker Compose برای هر دو پروژه

## روز ۹
- رفع باگ‌های نهایی، پاک‌سازی کد، حذف کدهای تست/debug
- تکمیل تست‌ها تا حداقل ۱۵ مورد برای بک‌اند
- آماده‌سازی برای جلسه‌ی تحویل + شروع نوشتن گزارش نهایی (در ویکی، طبق مستند درس) — این کار رو معطل نکنید، هر روز چند خط ازش بنویسید

## قانون طلایی هماهنگی
هر روز، ۵ دقیقه‌ی آخر رو به این اختصاص بدید: «چیزی که امروز پوش کردم و بقیه بهش وابسته‌ان؟» و در گروه تلگرام/دیسکورد اعلام کنید. این از بلاک شدن روز بعد جلوگیری می‌کنه.
