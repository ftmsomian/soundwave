# 🏁 چک‌لیست نهایی نمره‌دهی — فاز دوم (بک‌اند)

بر اساس بخش «چک‌لیست نهایی / فاز دوم» مستند پروژه، با مسئول پیشنهادی هر مورد:

- [ ] طراحی صحیح مدل‌ها (۵۰۰ نمره) — **مشترک، همه**
- [ ] رعایت قواعد REST (۵۰۰ نمره) — **مشترک، همه**
- [ ] وجود اندپوینت‌های CRUD به‌اندازه، نه بیشتر نه کمتر (۵۰۰ نمره) — **مشترک، همه**
- [ ] هندل کردن صحیح ارسال و دریافت فایل (۵۰۰ نمره) — **عضو۱ (آواتار) + عضو۲ (آهنگ/کاور)**
- [ ] ادغام با فرانت‌اند و کارکرد صحیح هر دو بخش (۱۰۰۰ نمره) — **مشترک، روزهای ۷-۸**
- [ ] وجود حداقل ۱۵ تست برای بک‌اند (۱۵۰ نمره) — **هرکس حداقل ۵ تست برای اپ خودش**
- [ ] رعایت اصول توسعه‌ی جنگو و استفاده از ابزارهای DRF برای عدم تکرار کد (۱۰۰ نمره) — **مشترک**
- [ ] استفاده‌ی صحیح و به‌جا از الگوهای طراحی (۲۰۰ نمره) — **مشترک (سرویس‌های accounting/payment، subscription_rules)**
- [ ] کد تمیز (۴۰۰ نمره) — **مشترک**
- [ ] تغییرپذیری کد (۱۵۰ نمره) — **مشترک (قیمت‌ها و محدودیت‌ها بدون تغییر کد قابل تغییر باشن)**
- [ ] داکرایز کردن هر دو پروژه (۳۰۰ نمره امتیازی) — **اختیاری، آخرین اولویت روز ۸/۹**
- [ ] فعالیت امتیازی انتخابی (۵۰۰ نمره امتیازی) — **در صورت تصمیم تیم، معمولاً روز ۹**

## چک‌لیست تکمیلی بر اساس اپ (داخلی خودمون)

### `accounts` (عضو ۱)
- [ ] ثبت‌نام کاربر عادی و هنرمند
- [ ] لاگین/توکن JWT + رفرش
- [ ] فراموشی/بازیابی رمز
- [ ] پروفایل (مشاهده/ویرایش/آپلود آواتار با محدودیت اشتراک)
- [ ] دنبال کردن/لغو دنبال کردن
- [ ] تنظیمات کاربر sync بین دستگاه‌ها
- [ ] Permission های مشترک (`core/permissions.py`) + تست سطح دسترسی

### `catalog` (عضو ۲)
- [ ] CRUD آهنگ/آلبوم با آپلود فایل
- [ ] جستجو/فیلتر/مرتب‌سازی
- [ ] استریم با محدودیت روزانه‌ی رایگان + دسترسی زودهنگام gold
- [ ] پلی‌لیست با سقف بر اساس اشتراک
- [ ] «آثار من» برای هنرمند با آمار واقعی

### `platform_ops` (عضو ۳)
- [ ] اعلانات (خودکار برای همه‌ی رویدادهای لازم)
- [ ] تیکت‌ها و مکالمه
- [ ] تأیید/رد هنرمند
- [ ] قیمت‌گذاری پویا بدون نیاز به تغییر کد
- [ ] خرید اشتراک + درگاه پرداخت sandbox + callback
- [ ] حسابرسی ماهانه محاسبه‌شده در بک‌اند + تسویه توسط مدیر
- [ ] گزارش‌های مدیر (توزیع اشتراک، درآمد)

## یادآوری مهم
گزارش نهایی پروژه (PDF گروهی طبق بخش «۴ گزارش نهایی» مستند درس) جدا از این چک‌لیست است و بدون آن نمره‌ی پروژه دریافت نمی‌شود. از همین حالا شروع به نوشتنش کنید (نقش هر عضو، مدل‌ها و روابطشان، نقش هوش مصنوعی در توسعه، نقاط قوت/ضعف آن).
